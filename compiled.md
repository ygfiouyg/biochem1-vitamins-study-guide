High-Yield Summary                                                                                                             24




            Vitamins are dietary organic compounds with catalytic/metabolic roles.

            Water-soluble group: vitamin C, B-complex and listed related compounds.

            Fat-soluble group: A, D, E and K.

            Vitamin C: reducing agent, collagen and iron absorption.

            Vitamin D: calcium/phosphate homeostasis and bone mineralization.

            Vitamin K: clotting-factor maturation.

            Vitamin E: antioxidant protection.

            Vitamin A: vision and epithelial integrity.




KEY POINT        Study each vitamin using the same pattern: chemistry → function → deficiency → toxicity/clinical relevance.
